## 📌 Project Header & Overview

### Business Logic & Purpose

**Adaptivly** is an end-to-end, AI-powered adaptive learning ecosystem and technical interview preparation platform. It is engineered to bridge the gap between passive computer science learning and active problem mastery for software engineers, CS students, and job seekers.

Unlike static coding platforms, Adaptivly continuously monitors user performance, error patterns, speed metrics, and topic accuracy to construct personalized learning trajectories. Powered by **Google Gemini 2.5**, **Judge0 Code Execution Engine**, and **Supabase PostgreSQL**, the platform provides real-time AI code tutoring, multi-language code sandbox execution, automated YouTube video-to-study-guide conversion, realistic AI technical mock interviews, diagnostic baseline assessments, and SM-2 spaced-repetition flashcards.

---

### ✨ Core User-Facing Features

- 🎯 **Adaptive Dashboard & Performance Heatmap**:
  - Real-time active streak tracking, 140-day contribution heatmaps, weekly activity bar charts, XP levels, and coin economy.
  - Dynamically generated learning recommendations generated by Google Gemini based on recent submission history and weakness profiles.

- 💻 **Interactive Multi-Language Coding IDE**:
  - Integrated Monaco Editor supporting **Python**, **JavaScript**, **TypeScript**, **C++**, and **Java**.
  - Isolated multi-test suite execution powered by the **Judge0 CE API** with real-time feedback on runtime (ms), memory footprint (KB), stdio outputs, and compilation errors.
  - Granular problem taxonomy with difficulty badges (Easy, Medium, Hard), topic tags, LeetCode/NeetCode references, hint toggles, solution breakdowns, and AI explanation engines.

- 🤖 **24/7 Context-Aware Gemini CS Tutor**:
  - Conversational AI tutor equipped with domain prompt presets (*Explain Code*, *Optimize Complexity*, *Debug Error*, *System Design Architecture*).
  - Full support for rendered LaTeX mathematical notation, code syntax highlighting, and persistent conversation session memory.

- 🎙️ **AI Technical Mock Interviewer**:
  - Simulated technical interview sessions spanning Data Structures & Algorithms, System Design, Frontend, and Backend specialization paths.
  - Interactive multi-turn question-answering with automated speech/text support.
  - Post-interview evaluation reports detailing score breakdowns across **Technical Accuracy**, **Problem Solving**, and **Communication**, accompanied by actionable growth recommendations.

- 📺 **YouTube Video to Interactive Study Guide**:
  - Automated transcript extraction from YouTube CS video lectures via `youtube-transcript`.
  - Gemini AI transformation into structured markdown summaries, key takeaways, code snippets, timestamps, auto-generated self-assessment quizzes, and flashcards.

- 🎴 **SM-2 Spaced Repetition Flashcards**:
  - Active recall review system driven by the SuperMemo-2 (SM-2) algorithm for optimal interval scheduling.
  - Instant AI flashcard generator that converts notes or topic prompts into structured card decks with mastery analytics.

- 📝 **Markdown Knowledge Base & Notebook**:
  - Full-featured Markdown notes manager featuring tag indexing, subject categorization, search, AI note expansion/summarization, and one-click flashcard extraction.

- 📅 **Intelligent Study Planner**:
  - Scheduled study task planner with priority queues (High, Medium, Low), deadlines, automated streak triggers, and task completion metrics.

- 📊 **Diagnostic Assessments & Learning Paths**:
  - Diagnostic skill assessment quiz engine to measure baseline proficiency across Data Structures, Algorithms, and System Design.
  - Structured, step-by-step curriculum roadmaps with prerequisite nodes and percentage progress tracking.

- 🏆 **Gamification & Leaderboards**:
  - Level-based XP progression, daily streak retention mechanisms, unlockable achievement badges, and user leaderboards.

## 🏗️ System Architecture & Data Flow

Adaptivly operates on a **hybrid client-server architecture** using TanStack Start server functions (`createServerFn`) and Nitro server routes. Data access is strictly controlled by Supabase Row Level Security (RLS) policies.

│                      TANSTACK START / NITRO SERVER ENGINE                       │
│                                                                                 │
│   ┌───────────────────────────┐         ┌───────────────────────────────────┐   │

### Detailed Request Life Cycle

1. **Client Interaction & State Management**:
   - The user triggers an action (e.g., submitting code in the editor, sending a prompt to the AI Tutor, or pasting a YouTube video URL).
   - `useAuth` retrieves the authenticated user's session JWT token from Supabase Auth (`supabaseBrowser`).
   - TanStack React Query dispatches a server call while handling optimistic loading and cache revalidation.

2. **Server Function & Authentication Guard**:
   - The request hits TanStack Start server functions (`src/server/functions/*.ts`) or server actions (`src/server-actions/*.ts`).
   - `src/server/auth.ts` intercepts the request, verifies the bearer JWT against Supabase Auth, and resolves the user ID (`auth.uid()`).

3. **Service & Execution Orchestration**:
   - **Code Execution Flow**: Code submissions are packaged with language runtime IDs and test case strings, then transmitted to the **Judge0 CE API**. Execution stdout/stderr, execution time, and memory usage are parsed and validated against test constraints.
   - **AI Generation Flow**: Prompts for tutoring, transcript summarization, or interview grading are sent to **Google Gemini** (`gemini-2.5-flash`). System instructions ensure structured JSON or clean Markdown responses.
   - **Transcript Extraction Flow**: YouTube URLs are parsed for video IDs; `youtube-transcript` extracts raw captions before piping them into Gemini for study guide synthesis.

4. **Database Persistence & Security**:
   - Database operations execute via `src/server/db.ts` using the privileged `SUPABASE_SERVICE_KEY`.
   - Results (submissions, XP updates, streak calculations, flashcard SM-2 review dates, chat history) are saved to PostgreSQL tables protected by Row Level Security (RLS) policies.
   - Response payloads flow back through TanStack Start server functions to the browser client, updating the UI reactively.

## 💻 Local Setup & Environment Guide

Follow these step-by-step instructions to set up and launch Adaptivly on your local machine.

### 📋 Prerequisites

Ensure you have the following installed on your development environment:
- **Node.js**: `v20.0.0` or higher (v22+ recommended)
- **Package Manager**: `npm` (v10+) or `bun` (v1.1+)
- **Git**: Latest version
- **Supabase Account**: Free tier project at [supabase.com](https://supabase.com)
- **Google Gemini API Key**: Free API key from [aistudio.google.com](https://aistudio.google.com/app/apikey)
- **Judge0 RapidAPI Key**: Free tier subscription at [RapidAPI Judge0 CE](https://rapidapi.com/judge0-official/api/judge0-ce)

---

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/adaptivly-mastered.git
cd adaptivly-mastered
```

---

### 2. Install Project Dependencies

Using **npm**:
```bash
npm install
```

Or using **Bun**:
```bash
bun install
```

---

### 3. Environment Variables Configuration

Copy `.env.example` to create your local `.env` configuration file:

```bash
cp .env.example .env
```

Open `.env` in your text editor and fill in the required environment variables:

```env
# ─── Supabase Configuration ───────────────────────────────────────────────────
# Obtain from: https://supabase.com → Project Settings → API
SUPABASE_URL=https://your-project-ref.supabase.co
SUPABASE_ANON_KEY=your-supabase-anon-key
SUPABASE_SERVICE_KEY=your-supabase-service-role-key

# Client-Side Supabase Keys (Exposed to browser build)
VITE_SUPABASE_URL=https://your-project-ref.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key

# ─── Google Gemini AI Configuration ───────────────────────────────────────────
# Obtain from: https://aistudio.google.com/app/apikey
GEMINI_API_KEY=your-google-gemini-api-key

# ─── Judge0 Code Execution Configuration ─────────────────────────────────────
# Obtain from: https://rapidapi.com/judge0-official/api/judge0-ce
JUDGE0_API_URL=https://judge0-ce.p.rapidapi.com
JUDGE0_API_KEY=your-rapidapi-key

# ─── Application Host Configuration ───────────────────────────────────────────
APP_URL=http://localhost:3000
```

---

### 4. Database Setup & SQL Migrations

1. Go to your [Supabase Dashboard](https://supabase.com/dashboard) and select your project.
2. Navigate to **SQL Editor** → **New query**.
3. Execute the SQL migration scripts located in the `./supabase/migrations/` directory in the following exact order:

   - **Step A**: Copy & run `supabase/migrations/001_schema.sql` *(Creates tables, constraints, & RLS policies)*.
   - **Step B**: Copy & run `supabase/migrations/002_functions.sql` *(Creates SQL helper procedures & streak triggers)*.
   - **Step C**: Copy & run `supabase/migrations/004_adaptive_learning.sql` *(Creates adaptive learning tracking schema)*.
   - **Step D**: Copy & run `supabase/seed.sql` *(Seeds initial 10 coding problems and starter code)*.

---

### 5. Launch the Local Development Server

Start the Vite / TanStack Start development server:

```bash
npm run dev
```

Or using **Bun**:
```bash
bun run dev
```

The application will be accessible at:
👉 **[http://localhost:3000](http://localhost:3000)**
